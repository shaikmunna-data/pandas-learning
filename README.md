# **🐼 Pandas Learning**

This repository contains my Pandas learning notebooks, practical examples, and sample datasets. It covers data manipulation and analysis using Pandas, progressing from fundamental operations to advanced techniques.

## **📚 Topics Covered**

- Series & DataFrames
- Data Import & Export
- Data Exploration
- Row & Column Selection
- Filtering & Sorting
- Data Cleaning
- String Operations
- GroupBy & Aggregation
- Merge, Join & Concat
- Pivot Tables & Data Reshaping
- Apply, Map & DataFrame.map
- Indexing
- Data Type Conversion
- Date & Time Operations
- Time Series Resampling
- Window Functions
- Working with Large Datasets
- SQL with Pandas

## **🛠️ Tools & Requirements**

- Python 3.x
- Visual Studio Code
- Jupyter Extension for Visual Studio Code
- Pandas
- NumPy
- OpenPyXL
- PyArrow
